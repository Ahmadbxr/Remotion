# Offscript — Paid-Social-Spot «Euer Können. Endlich sichtbar.»

Remotion-Projekt: `src/ad/` (Komposition, Choreografie, Layouts, zentrale
Konfiguration in `src/ad/config.ts`), Assets: `public/ad/`, Skripte:
`scripts/ad/`.

## Wichtig

Die Bildflächen zeigen **beschriftete Platzhalter**, weil die Originaldateien
von offscript.ch in der Produktionsumgebung nicht abrufbar waren. Echte
Kundenarbeiten einsetzen (5 Minuten pro Slot, siehe Anleitung), Freigaben
einholen, Voice-over aufnehmen — dann neu rendern.
